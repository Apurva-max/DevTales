# 🚀 DevTales

A modern full-stack blogging platform built with **React, TypeScript, Express.js, and MySQL**. DevTales enables users to create, edit, publish, and manage blogs using a rich text editor while interacting with the community through likes, comments, and bookmarks.

---

## 🌐 Live Demo

### Frontend
🔗 https://dev-tales-gules.vercel.app

### Backend API
🔗 https://devtales-production.up.railway.app

---

## ✨ Features

- 🔐 JWT Authentication
- ✍️ Rich Text Editor (Lexical)
- 📝 Create, Edit & Delete Blogs
- 🌍 Public & Private Blogs
- ❤️ Like Blogs
- 💬 Comment System
- 🔖 Bookmark Blogs
- 👤 User Profile Management
- 📊 Personal Dashboard
- 🖼️ Cover Image Upload (Cloudinary)
- 📱 Fully Responsive UI

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/DevTales.git
```

## Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

## Backend Setup

```bash
cd Backend
npm install
npm run dev
```
